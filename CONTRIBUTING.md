# Contributing

Thanks for wanting to help! Bug reports, ideas and pull requests are all welcome.

## Getting started

```powershell
pnpm install
pnpm dev
```

The app runs in a 1024×600 window when no dock screen is connected, so you don't need the hardware to work on it. Most features need Windows; the interface, tests and build also run on macOS and Linux.

Before opening a pull request:

```powershell
pnpm typecheck
pnpm lint
pnpm test
```

CI runs the same checks on Windows.

## Code style

- TypeScript everywhere, React function components, Tailwind CSS classes.
- Prettier formats the code (`pnpm format`): no semicolons, single quotes, 110 columns.
- Comments are in Italian, like the rest of the code base. English is fine in issues and pull requests.
- Touch first: buttons at least 44 px, no hover-only interactions, the layout must fit 1024×600.

## Translations

User-facing text goes through `t()` in the interface and `tr()` in the main process. The **Italian text is the key**:

```tsx
;<button>{t('Apri in VS Code')}</button>
say(t('Claude ha finito in {name}', { name }))
```

Then add the English version to [`src/shared/i18n-en.ts`](src/shared/i18n-en.ts):

```ts
'Claude ha finito in {name}': 'Claude finished in {name}',
```

`pnpm test` fails if a string used in the code has no English entry or if the placeholders don't match.

To add another language, create `src/shared/i18n-<code>.ts` with the same shape, register it in `src/shared/i18n.ts` (`Lang`, `translate`, `LOCALE`) and add it to the language picker in `src/renderer/src/settings/sections.tsx`.

## Windows helper

Audio and monitor control live in [`src/main/win/DockHelper.cs`](src/main/win/DockHelper.cs). It must compile with the C# 5 compiler that ships with Windows PowerShell 5.1: no string interpolation, no `out var`, no expression-bodied members. You can check it on any OS with Mono: `mcs -langversion:5 -target:library src/main/win/DockHelper.cs`.

## Yuyu's animations

The sprite sheet is generated by `scripts/buddy_gen.py` from `scripts/buddy-source.gif`. Change the script rather than editing `buddy.png` by hand, then run:

```powershell
python scripts/buddy_gen.py scripts/buddy-source.gif src/renderer/src/assets
```

## Releases

Maintainers: bump `version` in `package.json`, update `CHANGELOG.md`, then push a tag like `v0.6.0`. The release workflow builds the installer and publishes it to GitHub Releases.
